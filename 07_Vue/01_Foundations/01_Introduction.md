# Introduction

## 1. Why Vue Js
### Key Takeaways

* **Efficiency:** Vue.js is very lean (about 16KB) and allows for seamless browsing without needing to reload the server for every page.
* **Core Features:** Despite its small size, it includes powerful tools like **components**, filters, forms, and data binding.
  * **Getting Started:** The series will guide you through two main installation methods:
  * **CDN (Content Delivery Network):** A quick way to start locally for smaller projects.
* **Vue CLI & Webpack:** A professional setup recommended for larger, more complex applications.


* **Tools & Prerequisites:** The instructor recommends using the *Atom* text editor. Before starting, ensure you have a solid understanding of **JavaScript**, **HTML**, and **CSS**.
